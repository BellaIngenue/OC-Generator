# An Original Character Generator

A Web-based OC Generator for Artists, Writers, and Illustrators!!

Current Generation Rules:
- Eye Color: Blue, Green, Brown, and Other
- Hair Color: Brown, Blonde, Black, Red, Gray, and Dyed
- Personality Type: Calm, Chaotic, Extrovert, Introvert, Funny and IDK
- Siblings: 0, 1, 2, 3+
- Pets/Favorite Animal: 0, Dogs, Cats, Reptiles, Birds, Rodents, and Other
- Favorite Color: ROYGBIV, Pink, Black, White, Brown, and Gray
- Favorite Food: Fruits, Veggies, Grains, Dairy, Sweets, Protein
- OC Type: Fairy, Witch, Ghost, Food, Mermaid, Occult (Generalized), Silly, Surprise Me!
